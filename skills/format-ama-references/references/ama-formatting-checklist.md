# AMA reference-formatting checklist

Use this file as a working checklist, not as a substitute for the current official AMA pages.

## Source-of-truth hierarchy

1. Current AMA submission guidelines and reference-style examples.
2. Official publisher or DOI record for bibliographic facts.
3. User-supplied reference-check document for secondary comparison.
4. Existing bibliography text for the cited version and the user’s intended scope.

When these sources conflict, separate style questions from factual questions. AMA controls style; the authoritative publication record controls bibliographic facts; the manuscript context determines which version is being cited.

## Core patterns

The patterns below show structure only. Confirm punctuation, capitalization, access-date rules, and any source-type-specific requirements against the current AMA examples.

### Journal article

`Surname, Full First Name and Full First Name Surname (Year), “Article Title,” *Journal Title*, volume (issue), abbreviated page range.`

### Online-first journal article

Use the journal article format with the available publication metadata and DOI or article number when the current AMA examples call for it. Do not invent a volume, issue, or page range that has not yet been assigned.

### Book

`Surname, Full First Name (Year), *Book Title*, edition when applicable. City, State/Country: Publisher.`

### Chapter in an edited book

`Surname, Full First Name (Year), “Chapter Title,” in *Book Title*, Editor Name, ed. City, State/Country: Publisher, page range.`

### Working paper or unpublished manuscript

`Surname, Full First Name (Year), “Title,” working paper/unpublished manuscript, Department, Institution.`

Preserve a version date or series number only when it identifies the cited version.

### Conference paper or proceedings

Follow the current AMA example for the actual publication status. Distinguish a presentation, proceedings paper, extended abstract, and published conference article.

### Webpage, report, news, or magazine item

Use the current AMA source-type example. Verify the responsible author or organization, date, page title, publication/site title, and stable URL. Add an access date only when the current rule requires it.

## Author and year checks

- Verify author order; do not alphabetize coauthors within an entry.
- Use full given names when the authoritative record provides them reliably.
- Preserve particles, hyphens, suffixes, accents, and compound surnames.
- Treat organizations as authors only when the source does.
- Apply all-authors, repeated-author, and same-year `a`/`b` rules exactly as currently specified by AMA.
- Do not confuse online-first, copyright, issue, revision, or event years.

## Title and venue checks

- Reproduce the substantive title from the authoritative record before applying AMA capitalization.
- Preserve meaningful punctuation, acronyms, product names, and proper nouns.
- Use the journal’s official title, not an informal abbreviation, unless AMA requires an abbreviation for that source type.
- Italicize the journal, book, magazine, newspaper, or other container only where AMA requires it.
- Put article, chapter, webpage, and analogous item titles in quotation marks where the current examples require them.

## Volume, issue, and pages

- Verify volume and issue independently; do not infer one from the other.
- Preserve article numbers or e-locators when there are no conventional pages.
- Use an en dash for ranges.
- Abbreviate inclusive page ranges consistently with current AMA examples, such as `908–25`, while retaining enough digits to avoid ambiguity.

## Word layout defaults

- Title: `References`, centered, bold, Times New Roman 12 point.
- Page: one-inch margins.
- Body: Times New Roman 12 point.
- Entry: one paragraph, single-spaced unless the manuscript requires double spacing.
- Indent: 0.3-inch hanging indent.
- Paragraph spacing: 0 points before and after unless the manuscript template specifies otherwise.
- Remove legacy tables, floating objects, headers, footers, manual tabs, and manual line breaks unless required.

## Final comparison

Create a check table or internal audit with these fields:

- source-list identifier
- final first author and year
- final title
- authoritative verification source
- factual changes made
- unresolved issue

Use the audit to prove that every source survived and every factual change is traceable.
